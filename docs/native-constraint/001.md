# NullLiteralAnalyzer

FsNative does not support `null`. All optional values must use `Option` or `ValueOption`.

## Problem

```fsharp
// All of these will trigger the analyzer
let x = null
let y = if condition then value else null
match x with | null -> ... | _ -> ...
```

## Fix

Use `Option<'T>` or `ValueOption<'T>` instead:

```fsharp
let x: string option = None
let y = if condition then Some value else None
match x with | None -> ... | Some v -> ...
```

## Why This Matters for Native Compilation

`null` is a CLR concept that requires runtime support for null reference checking. In FsNative:

- All reference types have defined values
- Optional values are explicit via `Option<'T>` or `ValueOption<'T>`
- The compiler can generate more efficient code without null checks

## Error Code

`FSNATIVE-001`
