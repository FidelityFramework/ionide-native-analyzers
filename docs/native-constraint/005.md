# BclUsageAnalyzer

FsNative does not support BCL (Base Class Library) types. Use native types from the Alloy library instead.

## Problem

```fsharp
// These will trigger the analyzer
open System                           // FSNATIVE-005
open System.Collections.Generic       // FSNATIVE-005

let now: System.DateTime = System.DateTime.Now  // FSNATIVE-006
let _ = System.Console.WriteLine("test")        // FSNATIVE-007
```

## Fix

Use Alloy native equivalents:

```fsharp
// Instead of System.DateTime
open Alloy.Time
let now = Clock.now()

// Instead of System.Console
open Alloy.Console
Console.writeln "test"

// Instead of System.Collections.Generic.List<T>
// Use F# list, array, or Alloy collections
let items = [1; 2; 3]
```

## Allowed Namespaces

The following F# Core namespaces are allowed:

- `Microsoft.FSharp.Core`
- `Microsoft.FSharp.Collections`
- `Microsoft.FSharp.Control`

## Why This Matters for Native Compilation

BCL types depend on:

- .NET runtime (CLR)
- Garbage collection
- JIT compilation
- Platform-specific BCL assemblies

FsNative compiles to standalone native binaries without runtime dependencies. Alloy provides native implementations of common functionality with:

- Deterministic memory management
- Platform-native system calls
- No runtime overhead

## Error Codes

- `FSNATIVE-005`: `open System` or BCL namespace detected
- `FSNATIVE-006`: BCL type reference detected
- `FSNATIVE-007`: BCL member call detected
